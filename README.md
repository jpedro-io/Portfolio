## 📂 Projetos em Destaque

🚌 01. Transporte Universitário - Divisa Alegre (MG)

Portal leve e de alta performance criado para os estudantes universitários que viajam de Divisa Alegre para Vitória da Conquista.

Funcionalidades: Previsão do tempo via API em tempo real (Open-Meteo), consulta a regras/horários, guia de universidades e manual acadêmico.

Tech Stack: HTML5, CSS3, JavaScript Vanilla, Node.js e Vercel.

🛠️ 02. Oficina Luciano - Sistema de Gestão

Sistema voltado para a administração e balcão de atendimento de oficinas mecânicas.

Funcionalidades: Registro de Ordens de Serviço (O.S.), acompanhamento do status do veículo e histórico de manutenções.

Tech Stack: React, Vite, TypeScript e CSS.

🎮 03. CyberNode: Invasão de Rede

Jogo estratégico web com estética Cyberpunk focado na propagação em rede e Teoria dos Grafos.

Funcionalidades: Movimentação baseada na adjacência de nós, controle de recursos e algoritmos de busca.

Tech Stack: TypeScript, HTML5, CSS3.

🌐 04. Site New Tech

Página institucional moderna para apresentação de serviços de assistência técnica e soluções tecnológicas.

Funcionalidades: Layout responsivo, animações fluidas e canal direto de atendimento.
